# 9. ELIGIBILITY ENGINE

Build a rule-based eligibility engine first.

The engine should evaluate:

* Age
* Gender
* State
* Income
* Family size
* Occupation
* BPL status
* Rural/urban status
* Disability
* Maternal status
* Child-related requirements
* Healthcare requirement
* Other relevant scheme conditions

Return:

### Eligible

User satisfies the known criteria.

### Potentially Eligible

Some information is missing or eligibility depends on verification.

### Not Eligible

User clearly fails one or more required criteria.

Do NOT simply return yes/no.

Explain WHY.

Example:

"Potentially eligible because your income and state match the scheme criteria. Final eligibility may require verification through the official beneficiary database."

# 11. AI/ML RECOMMENDATION SYSTEM

Add an AI/ML recommendation layer on top of the rule-based eligibility engine.

The system should rank schemes based on user requirements.

Possible scoring:

```text
Eligibility Match = 50%
Healthcare Need Match = 20%
Demographic Match = 10%
Location Match = 10%
Income/Socioeconomic Match = 10%
```

Generate a recommendation score from 0–100.

Example:

```text
Ayushman Bharat PM-JAY
Match Score: 92%

High Match
```

Do NOT allow the AI model to override official eligibility rules.

The architecture should be:

User Data
↓
Rule-Based Eligibility Filter
↓
Eligible/Potential Schemes
↓
ML/AI Ranking
↓
Recommendation
↓
Explanation

This makes the system safer and more academically defensible.
